The source of truth in OKEngine is your application code. The **Manifest** is the compiled, strictly typed, and versioned JSON artifact (`manifest.v1.json`) that fully describes that model to the outside world.

You never author or edit the Manifest by hand; the compiler derives it automatically from your flows and element definitions.

<Callout title="Derived, Not Hand-Coded">
  The Manifest replaces OpenAPI specs, tRPC routers, custom MCP schemas, and observability
  instrumentation with one compiled contract.
</Callout>

```text
TypeScript Source → Compiler → Manifest (v1) → Client · Console · MCP · Traces
```

## One Contract, Multiple Surfaces

Every operational surface consumes the Manifest directly, guaranteeing zero drift between your backend logic and client tools:

| Surface                              | Target / Port             | Do You Maintain It?                          |
| ------------------------------------ | ------------------------- | -------------------------------------------- |
| **Typed Client** (`okengine/client`) | Frontend & API clients    | No — derived from Manifest                   |
| **Developer Console**                | Port `:6533`              | No — reads Manifest metadata directly        |
| **AI Agent MCP**                     | Port `:6535`              | No — flows expose as MCP tools automatically |
| **Architecture Graph**               | Console effect visualizer | No — derived from the flow effect ledger     |
| **Capability Matrix**                | Runtime security          | No — inferred from declared flow permissions |

## Manifest Diff & Blast Radius

Because the Manifest is a deterministic snapshot of your system capabilities, changing code produces a clear Manifest diff during development and CI.

- **Breaking Changes:** Removing an output field or modifying input schemas is flagged before deploying to production.
- **Blast Radius Analysis:** Inspect exactly which flows, signals, and client routes are affected when a store column changes.
- **Autonomous Audit:** Security teams and compliance tooling review contract changes rather than auditing thousands of raw code lines.
