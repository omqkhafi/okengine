Clock is how your backend **knows what time it is and schedules recurring work**. Time in backend engineering is notoriously brittle: timezones shift, distributed servers skew, and test suites struggle with flakey timers. In OKE, Clock is an explicit primitive.

<Callout title="The one rule">
  All time access and pauses must go through `fx.clock`. Direct calls to `Date.now()`, `new Date()`, or `setTimeout` bypass the deterministic execution engine and prevent time-travel during automated tests.
</Callout>

## What is Clock?

Clock provides three core capabilities:

1. **Named Schedules (`clock(...)`)**: Cron expressions with explicit IANA timezone support and distributed leader election.
2. **Intervals (`every(...)`)**: Relative duration loops (e.g. `every("10s")`) with jitter and per-tenant isolation.
3. **Durable Sleep (`fx.clock.sleep(...)`)**: Process-safe pauses that survive server reboots and node migrations.

```typescript title="src/clocks/billing.ts"
import { clock } from "okengine";

export const billingCycle = clock("billing.monthly", {
  cron: "0 0 1 * *",
  tz: "Asia/Riyadh",
});
```

## How Clock Executes Through fx

Inside any flow:

```typescript
// Deterministic current timestamp
const now = fx.clock.now();

// Durable sleep for days or minutes
await fx.clock.sleep("2d");
```
