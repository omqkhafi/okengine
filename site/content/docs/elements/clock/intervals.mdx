Intervals trigger Flows on fixed repeating intervals without the rigidity of full cron syntax.

## What it is

The `clock(name, { every: duration })` declaration accepts human-readable durations (`"10s"`, `"5m"`, `"1h"`). It includes optional jitter to avoid the "thundering herd" problem across large clusters.

## Smallest Example

<Steps>

<Step>
### Trigger flow on interval

```typescript title="src/flows/health/ping.ts"
import { on, flow, clock } from "okengine";

export const pingClock = clock("health.pingExternal", { every: "30s" });

export const pingExternalApi = on(
  pingClock,
  flow("health.pingExternal", {
    do: async (_, fx) => {
      // Periodic health check
    },
  }),
);
```

</Step>
