Named Schedules define persistent calendar triggers using standard cron syntax.

## What it is

A Schedule declared with `clock(name, { cron, tz })` registers a first-class named clock in the application manifest. Flows bind to it using `on(mySchedule, flow)`.

## Smallest Example

<Steps>

<Step>
### Declare schedule and flow

```typescript title="src/flows/reports/generate.ts"
import { clock, on, flow } from "okengine";

export const dailyReport = clock("reports.daily", {
  cron: "0 6 * * *", // 6:00 AM daily
  tz: "UTC",
});

export const runDailyReport = on(
  dailyReport,
  flow("reports.runDaily", {
    do: async (_, fx) => {
      // Runs every morning at 6:00 AM UTC
    },
  }),
);
```

</Step>
