Gate is how your backend **decides whether a caller may run a Flow**. Policies and rate limits attach to the
trigger with `.gate(...)`. Identity comes from `oke({ gate: { auth } })` into `fx.auth`; Gate policies
read that principal — they do not invent a separate middleware stack.

<Callout title="The one rule">
  **First denial wins.** Gates on a trigger evaluate left to right. The first reject stops the chain —
  later gates are skipped, and `do` never runs.
</Callout>

## What is Gate?

Four surfaces, one vocabulary:

1. **Policy (`gate.policy`, `gate.scope`)** — ABAC / scope checks over `auth` and request meta.
2. **Public (`gate.public` / `.public()`)** — intentionally unauthenticated HTTP posture.
3. **Rate (`gate.rate`)** — KV-backed throttle (`max` / `per` / `keyBy`).
4. **Auth config (`gate.auth`)** — sessions, keys, and optional tenancy under `oke({ gate: { auth } })`.

```typescript title="src/core/gate.ts"
import { gate } from "okengine";

export const member = gate.policy("member", {
  description: "Signed-in workspace member",
  check: ({ auth }) => !!auth.verified,
});

export const notesWrite = gate.scope("notes:write");

export const notesWriteRate = gate.rate({
  max: 60,
  per: "1m",
  keyBy: "ip",
  description: "Note write throttle",
});

export const notesMutate = gate.all(member, notesWrite, notesWriteRate);
```

## Attaching Gates to Flows

Gates chain on the **trigger**, not on a `gates: [...]` field inside `flow()`:

```typescript title="src/flows/notes/create.ts"
import { on, flow, http } from "okengine";
import { notesMutate } from "@/core/gate";

export const createNote = on(
  http.post("/notes").gate(notesMutate),
  flow("notes.create", {
    do: async (input, fx) => {
      // Guaranteed: verified member, notes:write scope, under rate
      return fx.json.create({ id: fx.id(), ...input });
    },
  }),
);
```

Open a route explicitly with `.public()` (or `.gate(gate.public)`). HTTP triggers that omit both a gate
and `.public()` fail boot with `GateBootError`.

## Denial codes

| Situation                                      | Code           | Status |
| ---------------------------------------------- | -------------- | ------ |
| Policy denied and no `auth.userId`             | `Unauthorized` | 401    |
| Policy denied and caller is authenticated      | `Forbidden`    | 403    |
| Rate gate burned                               | `RateLimited`  | 429    |
