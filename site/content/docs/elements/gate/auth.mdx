The Authentication Gate (`gate.auth`) validates caller identity before flow execution.

## What it is

`gate.auth` inspects Bearer tokens, session cookies, or API keys on incoming requests. On success, it populates `fx.user` and `fx.session`. If authentication fails, it rejects the request with HTTP 401 Unauthorized.

## Smallest Example

<Steps>

<Step>
### Protect a flow with gate.auth

```typescript title="src/flows/profile/me.ts"
import { on, flow, http, gate } from "okengine";

export const getProfile = on(
  http.get("/profile"),
  flow("profile.me", {
    gates: [gate.auth],
    do: async (_, fx) => {
      // fx.user is guaranteed non-null
      return { user: fx.user };
    },
  }),
);
```
</Step>
