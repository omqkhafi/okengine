The Tenancy Gate (`gate.auth.tenant`) extracts organization context and enforces tenant isolation boundaries.

## What it is

Multi-tenant SaaS applications need to ensure one customer cannot view or modify another customer's data. `gate.auth.tenant` resolves tenant identity from the request (e.g. `X-Tenant-Id` header, subdomain, or authenticated session) and attaches it to `fx.tenant`.

## Smallest Example

<Steps>

<Step>
### Protect tenant routes

```typescript title="src/flows/invoices/list.ts"
import { on, flow, http, gate } from "okengine";

export const listInvoices = on(
  http.get("/invoices"),
  flow("invoices.list", {
    gates: [gate.auth, gate.auth.tenant],
    do: async (_, fx) => {
      // fx.tenant contains active tenant context
      return await fx.store(db).query.invoices.findMany({
        where: (inv, { eq }) => eq(inv.tenantId, fx.tenant.id),
      });
    },
  }),
);
```
</Step>
