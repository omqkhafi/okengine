Secret Contracts (`vault.secret`) declare the credentials your backend requires.

## What it is

Instead of reading raw environment variables directly, secrets are declared with Zod schemas and descriptions. The runtime verifies that all required secrets exist at startup before taking traffic.

## Smallest Example

<Steps>

<Step>
### Declare secret contract

```typescript title="src/vault/resend.ts"
import { vault } from "okengine";
import { z } from "zod";

export const resendApiKey = vault.secret("resend.apiKey", {
  schema: z.string().startsWith("re_"),
  description: "Resend email delivery API key",
});
```
</Step>

<Step>
### Access in flow

```typescript
const key = await fx.vault.get(resendApiKey);
const resend = new Resend(key.reveal());
```
</Step>

</Steps>
