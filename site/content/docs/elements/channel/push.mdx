The Push medium (`channel.push`) and WhatsApp integration reach users directly on mobile devices and browsers.

## What it is

Channel handles VAPID key signing for WebPush, FCM token dispatch for iOS/Android, and WhatsApp interactive template messaging.

## Smallest Example

<Steps>

<Step>
### Send WebPush notification

```typescript title="src/flows/notifications/push.ts"
import { flow } from "okengine";

export const sendPush = flow("notifications.push", {
  do: async ({ subscription, message }, fx) => {
    await fx.sendWebPush(subscription, {
      title: "New Order",
      body: message,
      icon: "/icons/icon-192.png",
    });
  },
});
```
