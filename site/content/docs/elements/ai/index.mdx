AI is how your backend **incorporates machine intelligence into business processes**. Calling OpenAI or Anthropic through arbitrary SDKs creates unversioned prompts, unmonitored costs, and PII leakage. In OKE, AI is an explicit architectural primitive.

<Callout title="The one rule">
  **Bounded execution and declared budgets**. Every prompt and agent must specify input/output
  schemas and maximum cost budgets. Flows expose themselves directly as MCP tools to autonomous
  agents.
</Callout>

## What is AI?

AI spans four tightly integrated capabilities:

1. **Model Providers (`ai.model`)**: Swappable LLMs — local (Ollama, llama.cpp / vLLM / SGLang) and cloud (OpenRouter, OpenAI, …) with a verified provider registry for `baseUrl`.
2. **Versioned Prompts (`model.prompt`)**: Typed input/output contracts with cost caps and fallback routes.
3. **Bounded Agents (`ai.agent`)**: Multi-step tool-calling loops where tools are simply other Flows.
4. **Model Context Protocol (`ai.mcpServer` & `mcp.tool()`)**: Exposing your backend to external agents and Cursor.

```typescript title="src/ai/summary.ts"
import { ai } from "okengine";
import { z } from "zod";

export const smart = ai.model("smart", {
  provider: "openrouter",
  model: "openrouter/free",
  apiKey: process.env.OPENROUTER_API_KEY,
});

export const summarizeDoc = smart.prompt("docs.summarize", {
  in: z.object({ text: z.string() }),
  out: z.object({ summary: z.string(), tags: z.array(z.string()) }),
  budget: { maxCostPerCall: 0.02 },
});
```

## How AI Executes Through fx

```typescript
// Inside any flow:
const result = await fx.ask(summarizeDoc, { text: "..." });
```

The compiler records `asks: ["docs.summarize"]` in the Flow's manifest.
