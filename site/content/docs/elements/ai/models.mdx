Model Providers (`ai.model`) configure connection endpoints for AI models.

## What it is

OKE supports local offline inference for cost savings and privacy, alongside cloud API models. Providers are declared once and referenced across prompts.

## Smallest Example

<Steps>

<Step>
### Configure model in oke.config.ts

```typescript title="oke.config.ts"
import { defineConfig } from "okengine/config";

export default defineConfig({
  ai: {
    models: {
      "local-llama": {
        provider: "ollama",
        model: "llama3.2:latest",
        endpoint: "http://localhost:11434",
      },
      "fast-cloud": {
        provider: "openai",
        model: "gpt-4o-mini",
      },
    },
  },
});
```

</Step>
