Every provider below speaks a protocol oke already has a driver for — Postgres wire or Redis wire.
Hand the connection string to that driver and nothing else changes; no new driver id, no Flow
code changes.

<Callout title="The one rule">
  Vendor choice lives in a connection URL (`DATABASE_URL` / `REDIS_URL`) — never in
  `drivers.store.sql` / `drivers.store.kv`, which only ever say `postgres` or `redis`.
</Callout>
