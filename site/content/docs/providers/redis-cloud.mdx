Redis Cloud is Redis Ltd.'s first-party managed service — the same Redis you'd self-host, run and
patched for you. It's a plain TCP endpoint, no separate REST layer.

<Callout title="The one rule">
  Same `redis` driver, same `REDIS_URL` shape as a Redis image. Use `rediss://` (double `s`) for the
  TLS-required endpoint Redis Cloud publishes by default.
</Callout>

## Connect

```bash title="docker/.env.docker or your process env"
REDIS_URL=rediss://default:password@redis-12345.c1.region.cloud.redislabs.com:12345
```

Redis Cloud assigns a random high port per database — copy it from the database's connection
panel rather than assuming `6379`.

## Feature highlights

| Feature  | Notes                                                                                                                 |
| -------- | --------------------------------------------------------------------------------------------------------------------- |
| Protocol | Standard Redis (RESP) over TCP, TLS by default                                                                        |
| Modules  | Optional RediSearch / RedisJSON etc. — outside what oke's `redis` driver uses                                         |
| License  | Managed service under Redis Ltd.'s own terms — the RSAL/SSPL self-host restriction doesn't apply to you as a customer |
