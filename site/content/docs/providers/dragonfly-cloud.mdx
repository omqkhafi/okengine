Dragonfly Cloud is Dragonfly's own managed offering — the same multi-threaded engine as the
[image recipe](/docs/images/dragonfly), with a public TLS endpoint and passkey auth
generated for you.

<Callout title="The one rule">
  Same `redis` driver as any other Redis-wire target — Dragonfly Cloud's connection URI already uses
  the `redis://` (or `rediss://`) scheme, no translation needed.
</Callout>

## Connect

```bash title="docker/.env.docker or your process env"
REDIS_URL=rediss://default:passkey@xxxxx.dragonflydb.cloud:6385
```

Copy the ready-made "Redis-compatible Connection URI" from the data store's drawer in the
Dragonfly Cloud console — public endpoints ship with TLS and an auto-generated passkey by default.

## Feature highlights

| Feature    | Notes                                                                     |
| ---------- | ------------------------------------------------------------------------- |
| Protocol   | Redis-compatible (RESP), same client libraries as Redis                   |
| Auth       | Auto-generated passkey plus a Redis-compatible ACL system                 |
| Networking | Public endpoint by default; private networking recommended for production |
