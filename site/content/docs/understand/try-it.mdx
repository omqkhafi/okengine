Scaffold a backend. See which file is `GET /health`. Add a users routes file. Save a row.

Console on **6533** is derived from that code. API is **6530**. Stop after the first working POST if you want — keep reading for email, then the rest of the model.

<Callout title="The one rule">
  Every URL is a Flow: `on(trigger, flow({ do }))`. Talk to the database, mail, and clock only
  through `fx` (the second argument to `do`). In a many-routes file you write the path. In a
  one-route file you can omit it.
</Callout>

## Create

Your app runs on the host. Postgres, Redis, and mail run in Docker so local is the same _shape_ as production — protocol drivers, not a laptop-only stack.

<Callout title="Why Bun and Docker">

  [install](https://bun.sh/docs/installation). [Docker](https://docs.docker.com/get-docker/) runs
  Postgres / Redis / mail so local matches production; your app stays on the host.
</Callout>


## The files

OKE does not ship one folder layout. Roles matter: **Flow** is behavior, **Store** is data at rest, **root** is how the process boots. Names below are common — not a law.

| Role        | Meaning                                                                                | Often lives at                          |
| ----------- | -------------------------------------------------------------------------------------- | --------------------------------------- |
| Root config | Drivers and Docker images for `dev` / `test` / `prod`                                  | `oke.config.ts`                         |
| Boot        | `oke({ name })` — the process                                                          | `src/app.ts`                            |
| Flow        | Behavior: a URL, a job, a worker. A folder is a router; a file is a route (or several) | `src/flows/<router>/`                   |
| Store       | Tables and other data at rest. `db.declare` in config points here                      | `src/db/schema.ts` or `src/db/schema/`  |
| Vault       | Secret and config _names_ — not values                                                 | `src/vault.ts` or `src/core/vault.ts`   |
| Wiring      | Imported before `oke()` so store, mail, gates exist                                    | `src/core.ts` or `src/core/`            |
| Generated   | Catalog of Flows; SQL emit from your tables. Do not hand-edit                          | `src/flows/index.ts`, `src/db/drizzle/` |
| Tests       | `createTestApp` — deterministic drivers                                                | `tests/`                                |

The blank starter is one arrangement of those roles (`main/health.ts` is `GET /health`). Shorter splits `core/` and uses one file per verb. Both are OKE.

<Callout title="Write the path in a many-routes file">
  One file, one URL can omit the path. Next you put `GET` and `POST` in one file, so you write
  `"/users"` yourself. Pathless HTTP there fails **OKE1040**.
</Callout>

### Routes

Each export is one Flow. `CreateIn` / `UserOut` come from the Contracts step.

<Callout title=".public()">
  Every HTTP trigger needs `.public()` or `.gate(...)`. Omit both and boot fails (`GateBootError`).
  `.public()` means anyone may call — no session. `GET /health` already uses it. `.gate(member)`
  comes later when a route needs a signed-in user ([Gate](/docs/elements/gate)).
</Callout>

```typescript title="src/flows/users/index.ts"
import { on, flow, http } from "okengine/http";
import { z } from "zod";

// [!code focus:6]
export const list = on(
  http.get("/users", { out: z.array(UserOut) }).public(),
  flow("users.list", {
    do: () => [],
  }),
);

// [!code focus:6]
export const create = on(
  http.post("/users", { in: CreateIn, out: UserOut }).public(),
  flow("users.create", {
    do: async (input) => input,
  }),
);
```

</Step>

<Step>
### What comes back

Every HTTP Flow returns `{ data, error }` (optional `meta`). You return a value from `do`; the kernel wraps it. Failures are **values** — not thrown.

| Field   | Success                          | Failure                                                                         |
| ------- | -------------------------------- | ------------------------------------------------------------------------------- |
| `data`  | `out` — what `do` returned       | `null`                                                                          |
| `error` | `null`                           | `{ code, message?, data? }`                                                     |
| Status  | `200` (`fx.json.create` → `201`) | `422` if `in` fails; `fx.fail.notFound` → `404`; domain `fx.fail` codes → `400` |

Bad `in` never runs `do`:

```json
{
  "data": null,
  "error": {
    "code": "ValidationError", // [!code focus]
    "message": "The request failed validation."
  }
}
```

On the client, branch on `error` first:

```typescript
import { createClient } from "okengine/client";
import { app } from "@/app";

const api = createClient(app, "http://localhost:6530"); // [!code focus]
// [!code focus:4]
const { data, error } = await api.users.create({
  email: "you@localhost",
  name: "You",
});
// [!code focus:4]
if (error) {
  // error.code — ValidationError, or a code you declared with fx.fail
  return;
}
data.email; // [!code focus]
```

Full table: [HTTP · Response Envelopes](/docs/elements/flow/http#response-envelopes).

</Step>

## First Store

`src/db/schema.ts` was empty. `src/core.ts` already has `store.sql("app", { schema })` — do not move it.

```text
src/db/schema.ts     # you fill this
src/core.ts          # db is already here
src/flows/users/index.ts
```

<Steps>

<Step>
### Declare the table

```typescript title="src/db/schema.ts"
import { store, field } from "okengine";

// [!code focus:6]
export const users = store.schema.table("users", {
  id: field.id().primaryKey(),
  email: field.text().notNull(),
  name: field.text().notNull(),
  createdAt: field.timestamp().notNull().now(),
});
```

`oke dev` pushes schema. Identity and time go through `fx` — `fx.id()`, not a hand-rolled uuid.

</Step>

<Step>
### Read and write in the routes file

Widen `UserOut` with `id` and `createdAt` — same file as the other contracts (`index.ts` or `shapes.ts`):

```typescript
export const UserOut = z.object({
  id: z.string(), // [!code focus]
  email: z.string().email(),
  name: z.string(),
  createdAt: z.iso.datetime(), // [!code focus]
});
```

```typescript title="src/flows/users/index.ts"
import { db } from "@/core"; // [!code focus]
import { users } from "@/db/schema"; // [!code focus]

export const list = on(
  http.get("/users", { out: z.array(UserOut) }).public(),
  flow("users.list", {
    // [!code focus:6]
    do: async (_input, fx) => {
      return await fx.store(db).page(users, {
        orderBy: [users.createdAt],
        limit: 20,
      });
    },
  }),
);

export const create = on(
  http.post("/users", { in: CreateIn, out: UserOut }).public(),
  flow("users.create", {
    // [!code focus:8]
    do: async (input, fx) => {
      const [row] = await fx
        .store(db)
        .insert(users)
        .values({ id: fx.id(), email: input.email, name: input.name })
        .returning();
      return fx.json.create(row);
    },
  }),
);
```

`fx.json.create` is **201**. Declared `out` projects the row — extra columns strip; timestamps become ISO-8601.

</Step>

## First Signal

The POST should return the user before welcome-mail work runs. `signal.once` is a competing queue: one worker claims each message.

```text
src/signals/users.ts              # declare — not a URL
src/flows/users/index.ts          # emit after insert
src/flows/workers/welcome.ts      # bind worker
```

Keep the worker in its own unit. A Flow file next to `users/index.ts` is a generate error (`mixes a barrel index.ts with tree route files`).

<Steps>

<Step>
### Declare

Physics live on the Signal. The worker inherits this payload type — not `flow.in`.

```typescript title="src/signals/users.ts"
import { signal } from "okengine";
import { z } from "zod";

// [!code focus:9]
export const userRegistered = signal.once("users.registered", {
  schema: z.object({
    id: z.string(),
    email: z.string().email(),
    name: z.string(),
  }),
  retries: 3,
  deadLetter: true,
});
```

</Step>

<Step>
### Bind the worker

The worker is a Flow that is not a route. Name it — nameless `flow({ do })` here is **OKE1072**. `once` binds **one** worker; next section edits this `do`, it does not add a second `on`.

```typescript title="src/flows/workers/welcome.ts"
import { on, flow } from "okengine";
import { userRegistered } from "@/signals/users";

// [!code focus:6]
export const welcome = on(
  userRegistered,
  flow("workers.welcome", {
    do: async () => {},
  }),
);
```

</Step>

<Step>
### Emit after insert

In `create`, after the insert. `{ key: row.id }` is one job per user — retries stay ordered; different ids run in parallel.

```typescript title="src/flows/users/index.ts"
import { userRegistered } from "@/signals/users"; // [!code focus]

export const create = on(
  http.post("/users", { in: CreateIn, out: UserOut }).public(),
  flow("users.create", {
    do: async (input, fx) => {
      const [row] = await fx
        .store(db)
        .insert(users)
        .values({ id: fx.id(), email: input.email, name: input.name })
        .returning();
      if (!row) return; // [!code focus]
      // [!code focus:5]
      await fx.emit(
        userRegistered,
        { id: row.id, email: row.email, name: row.name },
        { key: row.id },
      );
      return fx.json.create(row);
    },
  }),
);
```

POST `/users` again — **201** is the same envelope. The worker runs after that response.

</Step>

</Steps>

## Split files or one mount

Optional. You already have a working routes file. These two shapes omit hand-written paths — **never mix them with `users/index.ts`**, and never put `list.ts` next to `route.ts`.

<Tabs items={["Split files", "One mount"]}>

<Tab value="Split files">

Delete `users/index.ts`. One verb per file. `list` / `create` / `get` do **not** add `/list` to the URL.

```text
src/flows/users/
  list.ts        # GET /users
  create.ts      # POST /users
  [id]/get.ts    # GET /users/:id
  shapes.ts
```

```typescript title="src/flows/users/list.ts"
import { on, flow, http } from "okengine/http";

export const list = on(
  http.get().public(), // [!code focus]
  flow({
    do: async (_input, fx) => fx.store(db).page(users, { orderBy: [users.createdAt], limit: 20 }),
  }),
);
```

Pathless `http.get()` is correct **here**. Shorter (`-t shorter`) is this tree in a real app.

</Tab>

<Tab value="One mount">

`store.resource` builds list / create / get / update / remove. `http.resource` mounts them. There is no pathless resource — pass `"/users"`.

```typescript title="src/flows/users/resource.ts"
import { store } from "okengine";
import { z } from "zod";
import { db } from "@/core";
import { users } from "@/db/schema";

// [!code focus:11]
export const usersResource = store.resource(db, users, {
  in: z.object({
    email: z.string().email(),
    name: z.string().min(1),
  }),
  out: z.object({
    id: z.string(),
    email: z.string(),
    name: z.string(),
  }),
});
```

```typescript title="src/flows/users/index.ts"
import { on, http } from "okengine/http";
import { usersResource } from "./resource";

export const usersApi = on(http.resource("/users", usersResource.all()).public()); // [!code focus]
```

Client: `api.users.list` / `.create` / `.get` / `.update` / `.remove`. Update is **PATCH**. Full table: [HTTP · Resources](/docs/elements/flow/http#resources).

## The rest of the model

Same app. One snippet each — not four more labs.

### Gate

You already used `.public()`. Every HTTP trigger needs `.public()` or `.gate(...)` — boot lists the gaps:

```text
gate boot failed — 2 trigger(s) missing auth posture (attach a gate or .public()):
  - users.list GET /users
  - users.create POST /users
```

A signed-in check is a policy on the trigger. Identity is `oke({ gate: { auth } })` plus a plugin — [Gate · Auth](/docs/elements/gate/auth), not this sitting.

```typescript title="src/core.ts"
import { gate } from "okengine";

// [!code focus:4]
export const member = gate.policy("member", {
  description: "Signed-in user",
  check: ({ auth }) => !!auth.verified,
});
```

```typescript
http.get("/users/me").gate(member); // [!code focus]
```

### Clock

Time is an element. `Date.now()` inside `do` is a defect. While `users/index.ts` is still the routes file, put the schedule **in that file** — do not add `expire.ts` beside `index.ts`.

```typescript
import { clock } from "okengine/http";

export const expire = on(
  clock.every("users.expire", "1h"), // [!code focus]
  flow("users.expire", {
    do: async (_input, fx) => ({ at: fx.clock.now() }), // [!code focus]
  }),
);
```

`fx.clock.now()` is epoch-ms. [Clock](/docs/elements/clock).

### Vault

`src/vault.ts` already lists contracts. Values resolve at boot — not in the file. Read through `fx`:

```typescript
import { publicApiUrl } from "@/core";

const origin = await fx.vault.get(publicApiUrl); // [!code focus]
```

Never log a revealed secret. [Vault](/docs/elements/vault).

### AI

Optional. `fx.ask` is the same door as `fx.store`. Needs a key — skip it to finish Try It.

```typescript
return await fx.ask(triage, { message }); // [!code focus]
```

## Troubleshooting

<Accordions>

<Accordion title="bun --version is below 1.4.2">
  OKE needs Bun ≥ 1.4.2 (`engines.bun`). Install or upgrade from
  [bun.sh/docs/installation](https://bun.sh/docs/installation), then `bun --version`.
</Accordion>

<Accordion title="Docker is not running">
  `oke dev` starts Postgres, Redis, and Mailpit in Compose so local matches production. Install
  [Docker](https://docs.docker.com/get-docker/), start the engine, then `bun run dev`.
</Accordion>

<Accordion title="OKE1040 — pathless HTTP never stamped">
  Cause: `Flow "{flow}" bound {method} with no path — the file-tree stamp never ran.` In
  `users/index.ts` pass `http.get("/users")`. Pathless `http.get()` belongs on one-file-per-route
  folders (`health.ts`, or `list.ts` after you delete `index.ts`).
</Accordion>

<Accordion title="Unit mixes index.ts with other route files">
  Cause: `Unit "users" mixes a barrel index.ts with tree route files.` Keep only `index.ts` (and
  `shapes.ts`). Signals in `src/signals/`; workers in another unit (`workers/welcome.ts`). After
  deleting `index.ts`, tree files (`list.ts` / `create.ts`) can share the folder.
</Accordion>

<Accordion title="OKE1072 — Signal or Clock flow unnamed">
  Cause: `A {kind} flow on "{trigger}" has no name.`
  Pass `flow("workers.welcome", { do })` on the Signal worker, `flow("users.expire", { do })`
  on a Clock in the routes file.
</Accordion>

<Accordion title="GateBootError — missing auth posture">
  Attach `.public()` or `.gate(...)` on every HTTP trigger. The error lists each gap.
</Accordion>

<Accordion title="VaultBootError at startup">
  TTY title **OKE1510**. A contract has no value in any resolution layer — set the missing names
  ([Vault](/docs/elements/vault)).
</Accordion>

</Accordions>
