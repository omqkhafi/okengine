Every recipe below is already wired into `oke docker` — pin an image in `oke.config.ts`
and get env, healthcheck, and a connection URL for free.

<Callout title="The one rule">
  Vendor choice lives in `images[…]` — never in `drivers.*`, which only ever say protocol
  ids (`postgres`, `redis`, `s3`, `smtp`, `openbao`, `meilisearch`, `ollama`, …).
</Callout>
