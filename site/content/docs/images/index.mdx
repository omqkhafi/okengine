Every recipe below is already wired into `oke docker` — pin an image in `oke.config.ts` and get
env, healthcheck, and a connection URL for free, no recipe code to write yourself.

<Callout title="The one rule">
  Vendor choice lives in `images["store.sql"]` / `images["store.kv"]` / `images.proxy` — never in
  `drivers.store.sql` / `drivers.store.kv`, which only ever say `postgres` or `redis`.
</Callout>
