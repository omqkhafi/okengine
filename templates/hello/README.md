# hello

Fastest possible okengine scaffold — one flow, no Store. This is an "it works"
starting point, not a lesson.

```bash
bun install
oke dev          # app :6530 · Console :6533 · MCP :6535
```

Try `GET /hello`. For the teaching path (comment-heavy apps with real domains),
see the `examples/` apps and `docs/spec/four-applications.md` in the okengine
repo — or scaffold with `bunx create-oke@latest <name> --from-example notes`.
